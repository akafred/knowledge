REA wires coding agents (Claude Code, Codex) into disassemblers such as Ghidra, Hopper and IDA through MCP so they can iteratively investigate compiled binaries, a dual-use capability that practitioners welcome for research and reconstruction but fear will erode the protection that binary distribution gave closed-source software.

Key terms

  • REA (Reverse Engineer Anything)
    An open-source MCP-based toolkit that lets coding agents drive disassemblers and static analyzers (Ghidra, Hopper, IDA, JS/Electron and .NET inspection) to investigate how compiled software implements features.
  • Reconstruction (vs. source recovery)
    Rebuilding the behavior of specific functions in testable form (e.g. matching all 3205 original x86 cases) rather than recovering the original source code, which REA explicitly does not claim.
  • Investigation flow
    The loop in which the agent queries a disassembler, inspects functions and cross-references, traces behavior, and iteratively tests hypotheses against the binary.

Propositions

  • explicitExposing reverse-engineering tools (Ghidra, Hopper, IDA) to coding agents via MCP servers lets agents inspect compiled binaries, trace function calls and work out how applications implement specific features.conf: high
  • explicitThe effective unit of AI-assisted reverse engineering is an iterative hypothesis-testing loop against the binary, not a one-shot decompile-and-summarize.conf: high
  • explicitREA reconstructs behavior but does not claim to recover original source code, and it runs locally.conf: high
  • implicitThe original binary acts as a test oracle for the agent's reconstruction: the DX-Ball sound-panning function was verified against all 3205 original x86 cases and 63 compiled function bytes, which is what makes the showcase credible.conf: high
    extendsCase Study: Refactoring at Scale with Agents · p9 — Both rely on an original game binary as deterministic ground truth for checking agent output; REA's DX-Ball verification generalizes the replayable-oracle enabling condition beyond refactoring to reconstruction.
  • explicitIt is disputed whether REA adds anything beyond asking a coding agent to install and use Ghidra; some practitioners report better results than their earlier attempts at agent-driven reverse engineering.conf: high
  • explicitIf AI makes reverse engineering of shipped binaries cheap, vendors will move applications to the cloud, because withholding the binary closes one channel of reverse engineering.conf: high
    extendsAndreessen Horowitz's Post · p11 — Adds binary opacity to the list of defences cheap coding agents erode, alongside integration switching costs.
  • explicitAI-assisted reverse engineering makes it easier to copy independent developers' games and apps, bypass paid features and exploit their work commercially without permission.conf: high
  • explicitValue is shifting from proprietary software to hardware: software was once king and hardware a commodity, but now hardware is king and proprietary software is becoming increasingly replaceable.conf: high
  • explicitA permissive MIT license plus a user-responsibility disclaimer is the project's whole answer to the legality and ethics of reverse engineering; authorization and legal compliance are pushed onto users.conf: high
  • implicitThe capability is inherently dual-use: the same agent-driven investigation serves legitimate research, interoperability and reconstruction as well as piracy and paywall bypass, and no license term can separate the two.conf: medium
  • implicitThe tool's credibility is signalled by popularity (over 200K GitHub stars) and curated showcases rather than by any systematic accuracy evaluation.conf: medium

Arguments

AI-assisted reverse engineering will weaken binary distribution as protection for closed-source software, and may push vendors toward cloud delivery.
Explicit premises:
  • REA lets agents trace function calls and reconstruct implementations from compiled binaries
  • Indie developers fear easier copying and paywall bypass
  • A commenter predicts a shift to cloud-hosted apps to withhold binaries
Implicit premises:
  • Binary opacity has been a meaningful practical barrier to copying software
  • Cheap capability becomes widely used, not only by the licensed or ethical
  • Vendors will respond with architecture changes rather than legal or licensing measures
Inferences:
  • Server-side and cloud-hosted logic becomes the new defensible layer, shifting control and risk to the vendor and trading away on-device and offline use
  • Software moats that depended on obscurity decay in the same way that integration moats are eroded by cheap coding agents
REA is a real capability gain over simply asking an agent to use Ghidra. strength: low
Explicit premises:
  • Practitioners report better results than previous attempts at agent-driven reverse engineering
  • Showcases reproduce functions with exact test matches
Implicit premises:
  • Showcase successes are representative of ordinary binaries
  • The MCP integration, not the underlying model improvements, produces the gain
Inferences:
  • A fair test would compare REA against a bare agent with Ghidra on the same binaries with the same model

Narratives

  • DX-Ball: reconstructing a sound-panning function from the classic game, with tests matching all 3205 original x86 cases.
    → Shows reconstruction can be verified exhaustively against the original binary, supporting the claim that the loop yields trustworthy output.
  • Touhou 4: recovering bullet-ring angle calculations from 16-bit DOS code.
    → Shows the toolkit extends to very old architectures and obscure code, supporting the breadth of the capability.
  • Notion's Electron clipboard implementation traced through JavaScript and Electron static analysis.
    → Shows the capability reaches modern commercial apps, which is exactly what makes the copying fears concrete.

Questions addressed

    MCP servers expose Ghidra, Hopper, IDA and JS/.NET analysis to coding agents, which investigate in an iterative loop and run locally.
  • ⭕ Does REA add value beyond a coding agent that is told to use Ghidra?
    Left as a Hacker News disagreement.
  • ⭕ What does cheap AI reverse engineering do to the economics and protection of closed software?
