Stacked Diffs / Stacked Pull Requests

Breaking a large change into a sequence of small, dependent pull requests/commits that build on each other and can be reviewed and merged in order — pioneered internally at Meta, productized by Graphite and Sapling, and (as of August 2026) natively supported by GitHub.

Also known as: stacked pull requests, stacked PRs, stacked diffs, stack (PR), Graphite, Sapling, GitHub Stacked Pull Requests
