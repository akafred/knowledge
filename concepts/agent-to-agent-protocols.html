Agent-to-Agent Protocols

Standards and conventions by which agents discover, negotiate with and delegate to other agents — the interoperability layer of the agentic web.

Also known as: A2A, A2A (Agent-to-Agent), agent-to-agent, agent card, Handshake (A2A handshake), open agent protocol, protocols (externalized), two-agent collaboration, shared interfaces
