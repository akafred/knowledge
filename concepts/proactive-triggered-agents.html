Proactive / Trigger-Driven Agents (Routines)

Agents started by a schedule, a repo event (e.g. a GitHub issue or PR) or a webhook rather than a human prompt. They run unattended on managed infrastructure and stay observable, steerable and resumable.

Also known as: routines, Claude Code routines, proactive agents, scheduled agent, scheduled agents, event-triggered agent, cron-triggered agent, webhook-triggered agent, agent triggers, /schedule, always-on agent
