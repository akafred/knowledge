Tool Manifest Integrity (Rug-Pull Defense)

Ensuring an agent's registered tool definitions (name, description, parameter schema) haven't silently changed since a client/operator trusted them — via hashing/pinning at registration, diff-based review, and behavioral baselines — since authentication and schema validation don't catch a tool whose meaning has drifted.

Also known as: manifest pinning, rug-pull attack, tool definition drift, capability attestation, semantic integrity, tool redefinition attack, schema drift

Part of: Agent Security

  • Article: Securing MCP in Production: Defense-in-Depth Beyond the Gateway Nik Kale · 2026-07-29 source ↗ Reader 🖥️
    Production MCP deployments need enforcement distributed across four distinct architectural layers — safe tool execution, an isolated management plane, a bounded outbound trust boundary, and pinned/monitored semantic integrity — each with its own earliest trustworthy enforcement point, because an API gateway can authenticate and authorize traffic but cannot safely execute tool logic, isolate management-plane infrastructure, contain a server's own outbound calls, or detect that a previously-trusted tool definition has changed.
