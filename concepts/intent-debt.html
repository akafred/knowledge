Intent Debt

The absence of externalized rationale, goals and constraints in artifacts agents can read — the one debt AI cannot pay down because the why must originate with humans.

Also known as: intent debt, Intent debt, externalize (intent), tacit intent, load-bearing rationale, cold start (of an agent session), plausible guess (about intent), externalization, cognitive artifacts

  • incompleteStorey's claim that cognitive debt 'has no equivalent' repayment mechanism is stated as an absolute, but the article never distinguishes understanding that was never built (plausibly unrecoverable) from understanding that was once held and has since decayed through disuse (plausibly recoverable via deliberate re-engagement, e.g. re-reading code or asking an agent to explain it back). This corpus's own Osmani extractions raise exactly that distinction and land on the opposite answer — that cognitive debt is partially recoverable this way — without either piece acknowledging the other's position.
    AI coding creates two kinds of debt. You're only measuring one — read next: extract-osmani-orchestration-tax-is-you#g5 (stock-and-flow model of cognitive debt, replenishment via re-reading) and extract-osmani-intent-debt#p5 (agents can 'partially pay down cognitive debt... re-explain the code') — see relations below for the direct tension.
  • incompleteThe Amazon outage is presented as an outcome of the exact context gap this article diagnoses, but the article's own cited source (CNBC) attributes the outage to "changes merged without proper review" — a review-gate failure — not to a documented absence of persisted intent, behavior, or conformance records specifically. The causal attribution to the context gap, versus a more generic review-diligence lapse, is asserted rather than demonstrated from the available reporting.
