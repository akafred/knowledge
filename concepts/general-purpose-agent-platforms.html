General-Purpose Knowledge-Work Agent Platforms

Consumer-facing agent products (Grok Bot, Cursor's "Sand," ChatGPT work agents) that generalize single-task coding-agent automation into persistent, multi-agent systems spanning general business applications — sales, marketing, ops — rather than terminal-based software development.

Also known as: general-purpose agent platform, persistent agent platform, agent platform (consumer), Grok Bot, business-workflow agents
