LLM-Driven Evolutionary Search

Using an LLM as a mutation/generation operator inside a classic evolutionary-search loop — generate candidates, score against a measurable fitness/eval function, iterate — applied to code, algorithms, or prompts rather than to the model itself.

Also known as: AlphaEvolve, evolutionary code optimization, genetic programming with LLMs, LLM mutation operator, program search, GEPA, prompt evolution
