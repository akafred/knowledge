Agent Config Decay

The tendency of coding-agent configuration (CLAUDE.md/AGENTS.md, skills, hooks, memory) to accumulate stale, over-specific rules as models and harnesses improve past what those rules were written for — driven by a self-reinforcing cycle where an agent's error prompts a new rule, the rule dilutes what matters, and adherence drops, producing more errors — so configuration needs periodic audit and test-by-removal rather than one-way growth.

Also known as: config decay, context file bloat, config half-life, rule accumulation cycle, config smell, agent config audit

Part of: Agent Context Files (CLAUDE.md / AGENTS.md)
