Loop Engineering

The engineering discipline of designing the outer, autonomous system — automations, worktrees, skills, plugins/connectors, sub-agents, and externally-persisted state — that repeatedly invokes an agent harness without a human prompting each turn. Broader than the inner agentic-loop architecture and sibling to agent-harness engineering.

Also known as: outer loop, the loop that prompts for you, automations, worktrees, skills, connectors, sub-agents, persisted state (agentic)

Part of: Agent Harness

  • What the Hell Is a Loop, Anyway? Laurie Voss · 2026-07-29 source ↗ Reader 🖥️
    The word 'loop' in mid-2026 AI-engineering hype names at least four architecturally distinct systems — execution, task, product, and system loops, each defined by what it iterates on and what ends it — plus an unnamed fifth ring above them, the oversight loop, where a human sets goals, allocates budget, and culls work; so the real engineering question isn't whether to build loops or which camp in the autonomy debate is right, but what information is needed to set the autonomy dial correctly at each of those five levels.
  • Software Factories, Light and Dark AddyOsmani.com · 2026-07-20 source ↗ Reader 🖥️
    Because verification, not generation, is the real bottleneck of an AI-driven 'software factory,' an engineer's central job is to decide loop by loop how much autonomy each part of the pipeline can earn — full automation ('dark') only where a check is cheap, fast, and hard to fake, human judgment ('lit') everywhere else — with the human's own role relocating from writing code to owning and verifying that outer decision.
  • What is “loop engineering?” The Pragmatic Engineer · 2026-07-14 Reader 🖥️
    “Loop engineering” — designing the orchestration around an AI coding agent (goals, completion checks, state persistence, fresh-context iteration) rather than hand-writing one-off prompts — is a real practice that originated as a DIY workaround (the “Ralph loop”) for small context windows, but by mid-2026 major harnesses had absorbed most of it into a native /goal primitive, so for most developers besides those building AI infrastructure, it is a largely-already-commoditized skill rather than a durable new discipline.
  • Loop Engineering Addy Osmani · 2026-06-07 Reader 🖥️
    Loop engineering means replacing yourself as the person who prompts the coding agent turn-by-turn with a designed system — automations, worktrees, skills, plugins/connectors, and sub-agents, plus externally-persisted state — that prompts the agent for you; but because that system can't distinguish between someone using it to move faster on work they understand and someone using it to avoid understanding the work at all, the engineer's judgement doesn't disappear, it relocates one level up, from prompting to system design, which Osmani argues is harder, not easier.
